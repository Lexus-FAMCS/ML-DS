# Fruits Detection on Images

## Overview

This project is aimed at detecting fruits in images using a deep learning approach. The main goal is to automatically identify and localize weapons within images.

## Dataset

The dataset is stored in the `dataset/` directory.

## Model

The detection model is located in the `model/` directory.  
The model is designed to detect and localize weapon instances in images.


## Results

The detection results  are saved in the `model/results/` directory.
