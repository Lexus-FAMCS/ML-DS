## Курс Deep Learning School (DLS)

### Решенные задачи
В рамках курса DLS были выполнены следующие проекты:

- `churn_kaggle_competition_prediction` - [Предсказание оттока клиентов](https://www.kaggle.com/competitions/advanced-dls-spring-2021) (Kaggle competition)
- `game_of_thrones_is_alive_prediction` - Предсказание выживания персонажей Игры Престолов
- `generative_models` - Генеративные модели(VAE и CVAE on MNIST dataset)
- `segmentation_task` - Задачи сегментации([on ADDI Project](https://www.fc.up.pt/addi/ph2%20database.html)) 
- `simpson_classification` - [Классификация персонажей Симпсонов](https://www.kaggle.com/competitions/journey-springfield) (Kaggle competition)
